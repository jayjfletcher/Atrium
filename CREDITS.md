# Credits

## Penguin UI

Atrium's Blade components are adapted from [Penguin UI](https://www.penguinui.com)
by Salar Houshvand, used under the MIT License.

Penguin UI is a copy-paste component library for Tailwind CSS and Alpine.js.
Atrium wraps its markup in Blade components, adds prop APIs and validation-error
handling, and compiles the styles into the stylesheet the package ships, so
consuming applications need no Tailwind build of their own.
